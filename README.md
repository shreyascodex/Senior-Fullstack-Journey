# Senior Full-Stack Journey

A personal learning repository documenting my progress through a full-stack web development journey. Each day focuses on practical frontend and web fundamentals, with projects and exercises built in HTML, CSS, and JavaScript.

## Overview

This repository contains daily practice work from the journey, covering foundational web development concepts, UI building, and responsive design skills.

## Project Structure

- Day 1: Intro and foundational web exercises
- Day 2: Continued frontend learning and small practice tasks
- Day 3: UI and layout-building exercises
- Day 4: More frontend development practice
- Day 5: Additional web design and implementation work
- Day 6: Book catalog table project

## Current Project

The latest work is in the Day 6 folder, specifically the Boot Catalog project.

This project includes a responsive HTML table displaying a collection of books with:
- table headers for Title, Author, Genre, and Publication Year
- five book entries in the table body
- a footer summary showing the total number of books

## How to View It

1. Open the folder for the project you want to view.
2. Open the index.html file in a browser, or use a local preview extension such as Live Server in VS Code.
