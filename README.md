# Senior Full-Stack Journey

This repository tracks my daily progress through a full-stack web development learning path. It includes hands-on practice, mini-projects, and UI exercises built with HTML, CSS, and JavaScript as I strengthen my frontend and web fundamentals.

## Overview

Each day focuses on a different skill or concept, helping me build practical experience with layout design, semantic HTML, responsive interfaces, and frontend problem solving.

## Repository Structure

- Day 1: Foundation exercises and introductory practice
- Day 2: Continued frontend learning and implementation tasks
- Day 3: UI and layout-focused projects
- Day 4: Additional frontend practice and design work
- Day 5: More web development exercises
- Day 6: Book catalog project and table-based data presentation

## Featured Project

### Book Catalog Table

The most recent project is in the Day 6 folder, under the Boot Catalog section.

This project includes:
- a semantic table structure
- column headers for Title, Author, Genre, and Publication Year
- five sample book records in the table body
- a footer total showing the number of books in the catalog

## How to Run

1. Open the project folder you want to view.
2. Open the corresponding index.html file in a browser.
3. For a smoother workflow, use a live preview extension like Live Server in VS Code.
