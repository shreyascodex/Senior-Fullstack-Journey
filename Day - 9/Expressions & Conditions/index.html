Expressions & Conditions

In JavaScript, expressions are combinations of values, variables, operators, and functions that are evaluated to produce a value. Conditions are used to perform different actions based on different criteria.

Example of an Expression

        const a = 5;
        const b = 10;
        const sum = a + b; // Expression that evaluates to 15

Example of a Condition

        const age = 18;
        if (age >= 18) {
            console.log("You are an adult.");
        } else {
            console.log("You are a minor.");
        }
